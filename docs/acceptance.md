# PRISM 展示页验收

## 已完成的实际检查

- **Chrome 桌面 1440 × 900**；手机布局采用 **390 × 844 的 iframe 视口**，经典滚动条使内容宽度为 375 px。两种宽度均无横向溢出。
- 首屏正向展开、反向复位后，曲线状态精确恢复。
- 12→II 舞台检查了滚动进度约 **0.08／0.42／0.74** 的三个关键画面。II 始终引用同一条 `#hf-II` 曲线；桌面和手机回到同一进度时，各导联的变换与透明度逐项相等，停滚后状态不变。
- 桌面原生滚轮完成 **0.08 → 0.686943 → 0.08**；手机视口中，两次 PageDown 将原生滚动位置从 **4155 → 5631 px**，两次 PageUp 精确返回 **4155 px**。
- 仅 II 导联阶段，单导联结果起点仍分别位于桌面／手机视口顶部以下约 **1462／1173 px**，均在视口外；继续滚动才进入结果。
- “静态阅读”按钮进入与 `prefers-reduced-motion` 相同的布局分支：完整 12 导联、额外 II 导联静态图及四项单导联结果均保留，解除固定舞台，没有长段空白。
- 内联脚本通过 `node --check`，文件通过 `git diff --check`。HTML 约 171 KB，无外部字体、图片、脚本或 `fetch` 依赖。

## 验证边界

- 未切换操作系统的“减少动态效果”设置；自动识别逻辑已做代码检查，静态布局通过页面按钮实际检查。
- 当前没有 Safari 环境，已审阅相关兼容代码，**未做 Safari 实机测试**。
- 手机检查为窄视口布局及原生键盘滚动，**不等同于真机触摸测试**。
- 云端浏览器不允许 `file://`，因此未实际用文件协议打开；自包含结构与无网络依赖已核对。

## 打开与部署

1. 下载仓库根目录的 `index.html`，直接用 Chrome 或 Safari 打开；页面不需要构建或安装依赖。
2. GitHub Pages 保留项目路径 `/prism-ecg-atlas/`，将该文件作为项目根目录入口即可。页面资源全部内联，站内跳转使用锚点。
3. 预览截图位于 `docs/previews/`；`docs/previews/responsive-review.html` 可在 HTTP(S) 预览中切换桌面／手机尺寸和关键场景。
